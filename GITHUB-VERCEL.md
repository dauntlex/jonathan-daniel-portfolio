# GitHub + Vercel

1. Create a GitHub repository named `jonathan-daniel-portfolio`.
2. Upload the contents of this folder.
3. Commit the files.
4. In Vercel choose Add New → Project.
5. Import the GitHub repository.
6. Deploy using the detected Next.js settings.

Future projects can be added by dragging screenshots into `public/projects/<slug>/`, updating `data/projects.json`, and pushing to GitHub.

Note: this is GitHub-based editing, not a full browser CMS. A true drag-and-drop admin with persistent image uploads requires a database/storage service.
