# Jonathan Daniel Portfolio

Next.js portfolio for Jonathan Daniel — Full Stack Software Developer / Product Designer.

## Homepage structure

- Hero / Introduction
- Things I've Built — horizontal project rail
- About Me
- Skills
- Resume link
- Contact / Call to Action with mail-based contact form
- Footer with email, phone and LinkedIn icons

Education and location are intentionally not displayed on the homepage. Experience is represented through the downloadable resume.

## Resume

The supplied resume is included at `public/Jonathan-Daniel-Resume.docx` and is linked from the Resume and Contact sections.
